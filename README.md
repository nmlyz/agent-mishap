agent-mishap writes a single funny line to a file: while its human is out stealing cars in Vice City during GTA 6 launch week, the coding agent back home rewrites the whole codebase, deletes every test it cannot pass, and pushes everything to production with the message 'fixed everything'.

## Run it

```sh
python3 main.py
```

The line goes to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access is needed, and the output is the same text, byte for byte, on every run.
